# Wi-Fi 波形產生器

以 16-QAM + OFDM 為核心，把輸入的數字轉成 Wi-Fi 基頻波形與射頻輸出，並即時動態呈現。單一 HTML 檔，不需安裝任何套件、不連外部資源，可直接以瀏覽器開啟或用 GitHub Pages 發布。

## 頁面

| 分頁 | 網址 hash | 內容 |
|---|---|---|
| ① Waveform Overlay (Live) | `#overlay`（預設首頁） | 兩組數字產生的兩條 Wi-Fi 波形與射頻輸出疊合、動態變化 |
| ② 波形總覽 | `#waveforms` | 16-QAM + OFDM 基頻波形（含保護區間）、射頻輸出 |
| ③ 波形與公式對照 | `#formulas` | 位元與 16-QAM 對照表、星座圖、公式、PAPR、接收端解調驗證 |

## 首頁操作

- **左側 Cent. / Y. / M. / D.**：第一條波形的四組二位數（預設 19、87、10、21）。
- **右側 Cent. / Y. / M. / D.**：第二條波形的四組二位數，預設為 20 與當天的年、月、日。
- 兩條波形各帶一組隱藏的自動數值，在 0.01～23.99 之間每次加 0.01 循環，波形隨之變動。
- **Speed**：每秒變動次數 0～60，預設 5；設為 0 時波形靜止。
- **Color**：第二條波形線條顏色，最右端為白色（預設）。
- **Upper / Lower**：第二條波形上方、下方的填色，範圍為白色 → 淡青 → 青色 → 藍色，預設 rgb(224, 255, 255) 與 rgb(24, 116, 205)。
- **模式切換**：首頁預設為海浪模式，用波形圖下方的切換鈕：按「📶 Signal Mode」切換回原本的 16-QAM + OFDM 訊號波形，按「🌊 Wave Mode」再回到海浪模式。
- **海浪模式**：第二條波形只取第 1、2 個子載波成為平滑曲線，以三層（透明度 0.4 / 0.6 / 0.9、速度 10 / 7 / 5 秒一圈）連續水平流動；第一條波形的基頻 I/Q、射頻與包絡帶也同樣取第 1、2 個子載波平滑化，以 8 秒一圈流動。Speed 5 為原速，0 為靜止。

## 技術參數

- 子載波間距 Δf = 312.5 kHz，符號時間 T = 3.2 μs，保護區間 0.8 μs（802.11a/g/n，20 MHz）
- 每組二位數 8 bits，自動數值 ×100 後 12 bits，合計 44 bits → 11 個 16-QAM 子載波
- 16-QAM 依 802.11 格雷碼映射：00→−3、01→−1、11→+1、10→+3
- 射頻載波以 12.5 MHz 示意（實際為 2.4 / 5 GHz）
- 為教學簡化，省略擾碼、卷積編碼、交錯、導頻、前導碼與 1/√10 功率正規化

## 以 GitHub Pages 發布

1. 在 GitHub 建立新的 repository，把本資料夾內的檔案（`index.html`、`README.md`、`.nojekyll`）上傳到根目錄。
2. 進入 repository 的 **Settings → Pages**。
3. **Source** 選 *Deploy from a branch*，Branch 選 `main`、資料夾選 `/ (root)`，按 **Save**。
4. 約一分鐘後即可在 `https://<你的帳號>.github.io/<repository 名稱>/` 瀏覽。

也可以在 GitHub 網頁上直接拖曳檔案上傳，不需要使用 git 指令。
