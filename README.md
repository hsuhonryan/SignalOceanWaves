# Wi-Fi 波形產生器

以 16-QAM + OFDM 為核心，把輸入的數字轉成 Wi-Fi 基頻波形與射頻輸出，並即時動態呈現。單一 HTML 檔，不需安裝任何套件、不連外部資源，可直接以瀏覽器開啟或用 GitHub Pages 發布。

## 頁面

| 分頁 | 網址 hash | 內容 |
|---|---|---|
| ① Waveform Overlay (Live) | `#overlay`（預設首頁） | 四組數字產生的海浪波形／Wi-Fi 訊號波形與射頻輸出疊合、動態變化 |
| ② 波形總覽 | `#waveforms` | 依首頁模式顯示：Wave Mode 為海浪層、四條線、射頻輸出（同步流動）；Signal Mode 為 16-QAM + OFDM 基頻波形（含保護區間）與射頻輸出 |
| ③ 波形與公式對照 | `#formulas` | 依首頁模式顯示：Wave Mode 為各層海浪與各條線的位元、符號、展開公式與參數；Signal Mode 為 16-QAM 對照表、星座圖、公式、PAPR、解調驗證 |

② ③ 分頁只使用四組欄位（32 bits、8 個子載波），不含首頁的自動數值。

## 首頁操作

- **左側 Cent. / Y. / M. / D.**：決定四層海浪（訊號模式下為上下填色），預設 19、87、10、21。
- **右側 Cent. / Y. / M. / D.**：決定四條線與射頻輸出（訊號模式下為 I/Q 線），預設為 20 與當天的年、月、日（例：2026/11/16 → 20、26、11、16）。
- 另有一組隱藏的自動數值，在 0.01～23.99 之間每次加 0.01 循環，訊號波形隨之變動。
- **Speed**：每秒變動次數 0～60，預設 2；設為 0 時波形靜止。
- **Color**：所有線條（海浪模式的四條線、訊號模式的 I/Q 線）的顏色，最右端為白色（預設）。
- **Upper / Lower**：訊號模式下為曲線上方、下方的填色；海浪模式下 Upper 為背景、Lower 為最上層（第 4 層）海浪的顏色。範圍為白色 → 淡青 → 青色 → 藍色，預設 rgb(224, 255, 255) 與 rgb(24, 116, 205)。
- **模式切換**：首頁預設為海浪模式，用波形圖下方的切換鈕：按「📶 Signal Mode」切換回 16-QAM + OFDM 訊號波形，按「🌊 Wave Mode」再回到海浪模式。

### 海浪模式公式

每一層海浪取一個欄位的 8 bits，拆成 2 個 16-QAM 符號 X₁、X₂，當作第 1、2 個子載波：

```
w(t)  = I₁·cos(ωt) − Q₁·sin(ωt) + I₂·cos(2ωt) − Q₂·sin(2ωt)      ω = 2π/T
yᵢ(t) = (10 / max|w|) · w(t + τᵢ) + dᵢ
dτᵢ/dt = (Speed / 5) · T / Dᵢ
```

| 層 | 欄位 | 流動一圈 Dᵢ | 垂直位移 dᵢ | 顏色 |
|---|---|---|---|---|
| 1 | Cent. | 10 秒 | 0 | rgba(0,150,255,0.4) |
| 2 | Y. | 7.5 秒 | −6 | rgba(0,120,220,0.6) |
| 3 | M. | 5.5 秒 | −12 | rgba(0,90,190,0.9) |
| 4 | D. | 4 秒 | −18 | 由 Lower 桿決定（預設 rgb(24,116,205)） |

四條線（顏色由 Color 桿決定）取右側欄位，公式與海浪相同（取實部 I），並與同編號的海浪層同速、同高度流動：

| 線 | 右側欄位 | 樣式 | 流動一圈 |
|---|---|---|---|
| 1 | Cent. | 粗實線 | 10 秒 |
| 2 | Y. | 細實線 | 7.5 秒 |
| 3 | M. | 粗虛線 | 5.5 秒 |
| 4 | D. | 細虛線 | 4 秒 |

射頻細線與淺藍包絡帶取右側 Cent. 的 2 個符號，與第 1 條線同速流動。

## 技術參數

- 子載波間距 Δf = 312.5 kHz，符號時間 T = 3.2 μs，保護區間 0.8 μs（802.11a/g/n，20 MHz）
- 每組二位數 8 bits，自動數值 ×100 後 12 bits，合計 44 bits → 11 個 16-QAM 子載波
- 16-QAM 依 802.11 格雷碼映射：00→−3、01→−1、11→+1、10→+3
- 射頻載波以 12.5 MHz 示意（實際為 2.4 / 5 GHz）
- 為教學簡化，省略擾碼、卷積編碼、交錯、導頻、前導碼與 1/√10 功率正規化

## 以 GitHub Pages 發布

1. 在 GitHub 建立新的 repository，把本資料夾內的檔案（`index.html`、`README.md`、`.nojekyll`）上傳到根目錄。
2. 進入 repository 的 **Settings → Pages**。
3. **Source** 選 *Deploy from a branch*，Branch 選 `main`、資料夾選 `/ (root)`，按 **Save**。
4. 約一分鐘後即可在 `https://<你的帳號>.github.io/<repository 名稱>/` 瀏覽。

也可以在 GitHub 網頁上直接拖曳檔案上傳，不需要使用 git 指令。
